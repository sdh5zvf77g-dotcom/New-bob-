AI Bob - setup (iPhone only)
1. In Safari go to github.com, make a public repo, upload index.html and icon.png.
2. Settings > Pages > Deploy from branch: main, / (root).
3. Open https://YOURNAME.github.io/REPONAME/ in Safari (not inside another app).
4. Share > Add to Home Screen.
5. Open the app > gear icon. Provider "On-device (free, no key)": pick a model, tap Download & load model (needs Wi-Fi, ~1 GB, once). Then chat offline.
   Or choose OpenAI/Anthropic and paste an API key.
Import Crazy Bob memory: brain icon > Import file.
